> Iglooghost 是英国电子音乐人与视觉艺术家西默斯·罗尔斯·马利亚（Seamus Rawles Malliagh）的个人项目。他于 2015 年被 Flying Lotus 发掘并签约至 Brainfeeder 厂牌，随后凭借独特的极速电子风格与庞大的自创视觉神话体系在实验舞曲领域异军突起。
> 
> Iglooghost 的音乐以高密度、极快节奏（通常在 160 BPM 以上）和高度解构的制作手法著称。他巧妙融合了 Wonky、Deconstructed Club、Footwork 与 Footwork Jungle 等风格，用极其精细的切碎采样式编排，将高亢清脆的合成器音效、卡漫化的声音采样与沉重的低音相结合，营造出充满童趣却又高度暴力的数字最大化主义声音。不仅如此，他将音乐视为完整视觉宇宙的一部分，从封面绘画、文字符号到动画设计均独立完成。在其代表作《Neō Wax Bloom》中，他通过音乐讲述了一个关于虚构生态系统的奇幻故事；而在《Lei Line Eon》与《Tidal Memory Exo》等后期作品中，他又将创作延伸至室内乐采样、地脉电学与工业污浊质感的多元探索。作为当代解构舞曲与 IDM 领域最具辨识度的创作人之一，Iglooghost 展示了数字时代音乐与世界观建造相融合的极具前瞻性的可能性。

### Lei Line Eon（2021）

![](https://f4.bcbits.com/img/a1491488233_10.jpg)

> 《Lei Line Eon》（参考译名《地脉纪元》）是英国电子音乐人与视觉艺术家 Iglooghost 于 2021 年在其自创厂牌 Gloo 下发行的第二张完整个人专辑。相比首张专辑《Neō Wax Bloom》中极度密集、充满卡通色彩的数字狂欢，本作标志着其声音美学向有机电子声学与现代古典领域的深刻转型。
> 
> 专辑以虚构的“地脉力学”为核心世界观，讲述了通过声音频率唤醒古老地理能量与奇幻生物的伪学术故事。在音乐制作上，Iglooghost 巧妙地将复杂的解构舞曲框架、UK Bass 脉冲与小提琴、大提琴及木管等室内乐原声采样融为一体。切碎而精密的 Footwork 鼓点与充满泥土感的击打音效交织，在沉静肃穆的古典和声与骤然爆发的异样电子噪音之间自由穿梭。借助配套的配图说明、虚构研究所企划与高饱和度视觉艺术，Iglooghost 将音乐扩展为一个跨媒介的迷幻科幻实体。《Lei Line Eon》不仅展现了他在宏大世界观建造上的卓越才能，更为未来主义电子与前卫古典的结合拓宽了极具辨识度的边界。
