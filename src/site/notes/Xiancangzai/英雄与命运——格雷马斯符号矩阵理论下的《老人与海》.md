### 英雄与命运——格雷马斯符号矩阵理论下的《老人与海》

格雷马斯的符号矩阵理论认为，故事的受众所接触的“意义”，产生于“语义素”单位间的两组基本对立：实体与实体的对立面、实体与对实体的否定。在矩阵模式中，设立一项实体为 X，它的对立一方为反 X，与 X 矛盾但并不一定对立的为非 X，反 X 的矛盾方为非反 X。故事起源于 X 与反 X 的对立，完成于非 X 与非反 X 的引入与展开。以此理论，抛开海明威的电报式的简明语言与笔法，对《老人与海》的叙事结构作如下解析：

![{20904D65-E299-4810-B364-28C0E27D0050}.png](/img/user/%E9%99%84%E4%BB%B6/attachment/%7B20904D65-E299-4810-B364-28C0E27D0050%7D.png)

老人与海，两者构成命运的张力，在“老人——海”的主客二元对立中，命运的悲剧之网悄然扭结，形成莫比乌斯带式的拓扑结构。海作为生存的战场，作为个体存在同命运搏击的舞台，集中展示了两种相互作用力，自西班牙语中渔民对海的两性称谓可窥一斑：Lamar 与 elmar——母性的抵抗与父性的复仇。

抵抗者以“非 X”的实体出现，比船更长的马林鱼温和地拖着船走，为后文的狂暴与绝望做铺垫的，只是如此的海洋的阴性面。海燕，海龟，大马林鱼……都绘以悲剧英雄的暗色调。海明威以悲悯之眼，赞颂之笔让英雄们复活，让老人与大海上其他沉默的生灵一同加冕，而作为人类，老人不过不可避免地站上了第一个台阶而已。老人（X）被突出成了命运信封上的小小的邮票，是被作者隐藏的社会的舞台，舞台上，放置着满是补丁的衬衫，遥不可及的垒球比赛，深刻的皱纹，褐色的肉瘤，贫穷与“倒了血霉”，孩子的自由与父亲的控制间的矛盾对立（“母性的抵抗”与“父性的复仇”之又一喻），诸如此类，已是英雄出场时的标准布景，作为布景，或许可以说是更见本质之物，是老人真正意义上的船。而大马林鱼与其理解为挣扎三天三夜的抵抗者，毋宁归于老人的同行者，二者正如古罗马斗兽场的双方，被高高在上的命运玩弄观赏、被读者咀嚼分析，二者的对立姿态只是充满戏剧性的表象，而其实质——对命运的反抗——反而将彼此拧得更紧，这正是为何老人的“朋友”如此之多：海、飞鱼、大马林鱼、抽筋的右手、棚屋的床以及报纸，老人不加选择地移情，称呼对手为“兄弟”，正凸显了英雄悲剧性的孤独，需要将自我外化来反观自身，找到逃出孤独之雾的航路。在“人——兽”或“人——自然”的传统的二元对立视角下，抵抗似乎同道德无涉，然而联系二战后的现代性反思，不难看出“老人与海”的寓言中对于人类战争的悲剧性与荒谬性的隐喻，与人类个体的有限性在命运的不可抗力下的“二律背反”的矛盾与道德难题。这颇可以溯源至人类对战争的普遍反思与海明威在早中期反战小说中的独立经验。同时，大马林鱼以非人类的身份，作为“敌人”的尊严的获得，正是作者人道主义的投射，“硬汉精神”的审美性与道德性的泛化提升。

鲨鱼（反 X）作为复仇者的出现，将悲剧推向了顶点。“它游得那么快，什么也不放在它眼里。”鲨鱼未被赋予人性，而作为命运的使徒，它甚至具有了部分神性，它被描绘成完全中立的、偶然却“并非偶然”的插入者，那姗姗来迟却又必然来到的、恍若命运不可抗拒的敕令，恍若将耶稣钉上十字架的手钉掌钉，甚至不是预示，而是失败与毁灭的直接宣告。这里，“失败”作为普遍象征，代表了相对的人类个体在绝对的集体环境中的命运。连续三个星期每天都捉到大鱼并不是命运，而只是运气，甚而是对于崇高的实现的阻碍。当群鲨一口一口咬去大马林鱼肉，一个终极却又日常性的选择与思考像白色的鱼骨一样裸呈于读者之眼：作为一个渺小的个体存在，如何面对必然的失败？

这个问号即是在 X 与反 X 之间回荡的小说的核心主题。在选择之间，体露出“非反 X”——作为一种人文主义普遍原则存在的硬汉精神。这种精神和原则在老人桑地亚哥身上的发现，是一种行动上无所畏惧、思想上却矛盾不堪的英雄主义：在为读者称道了半个世纪的向死而生的对人类尊严的自卫中，他始终不以“英雄”“硬汉”自视，甚至对孩子说：“它们把我给打败啦，曼诺林。”仿佛已经承认“一个人不是生来就要被打败的，你尽可以消灭他，但就是打不败他。”的悲壮宣言悉告破灭，最终呈现出无目的的虚无。尽管结尾老人和孩子商量未来一道出海打渔的一笔将硬汉精神刻入人心，然而“狮子”仍然在梦里，运气渺然无寻，小说不肯透露硬汉的最终归宿。然而如或有“硬汉主义”的纲领，“归宿”是一定要给排除在外的。孩子明白老人并未被打败，这种“成功”并非出于阿 Q 式的精神胜利，乃出于对人类的存在本身的信心，一种英雄主义的精神信仰。

海明威最初否认《老人与海》的象征含义，“大海就是大海。老人就是老人。孩子就是孩子，鱼就是鱼。鲨鱼就是鲨鱼……”但正如伯纳德·贝瑞孙所言：“任何一部真正的艺术品都散发出象征与寓言的意味。”海明威最后也承认：“如果我能把它们描写得足够真实的话，他们会意味着许多东西。”真实的人与物，成为具有强烈象征的符号，这“意味着”的“许多东西”，在格雷马斯的框架中，不排除英雄与命运二重奏的神话原型，亦不排除对个人存在意义的深沉思考，亦不排除纯粹对于硬汉精神的体认。固然，将故事拆解，将意象符号化难免有过度阐释的嫌疑，格雷马斯结构主义自身有不可避免的缺点，有一群让它的劳碌化为乌有的凶猛鲨鱼，然而，符号矩阵理论的框架确实能为我们提供一种《老人与海》 的阐释范式，特别是我们意欲挖掘隐藏于其中的象征意义时，特别是我们意欲潜入深海，去窥探冰山未曾显露的八分之七时，符号矩阵理论确乎是一套合身的潜水服。
